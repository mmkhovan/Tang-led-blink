# 🔆 Blink LED для TANG NANO 20K

Простой проект на Verilog для FPGA-платы **TANG NANO 20K** от Sipeed (GW2AR-LV18QN88C8/I7), реализующий мигание светодиодом с заданной частотой. Идеально подходит как "Hello World" проект для изучения FPGA и Gowin IDE.

## 📦 Состав проекта

- `led.v` — основной Verilog модуль, реализующий мигание светодиода
- `led.cst` — constraints файл с привязкой пинов к светодиоду и клок-сигналу. Только конечно констрэйнты блять надо создавать для каждого модулей отдельные
- `led.sdc` — тайминговые ограничения (27 МГц клок)
- `README.md` — описание проекта

## ⚙️ Используемые ресурсы

- FPGA: **GW2AR-LV18QN88C8/I7**
- Плата: **TANG NANO 20K**
- IDE: **Gowin IDE** ([скачать с сайта Gowin](https://www.gowinsemi.com/en/support/download/))
- Тактовый генератор: **27 МГц**
- Напряжение I/O: **1.8V** (Bank 6 и 7)

## 🔌 Подключение

| Название | Назначение         | Пин (QN88) |
|----------|--------------------|------------|
| `sys_clk` | Входной клок       | `IO4`      |
| `led`     | Светодиод (GPIO)   | `IO15`     |

## 🛠 Как собрать

1. Открой проект в **Gowin IDE**
2. Определи .v файл в котором указан нужный для запуска Top Module.
3. Запусти:
    - `Synthesis`
    - `Place & Route`
    - `Generate Bitstream`
4. Перейди в **Tools → Programmer** и прошей:
    - `SRAM` — для временной загрузки
    - `SPI Flash` — для постоянной

## 💡 Как это работает

Счётчик считает полсекунды (на частоте 27 МГц), после чего переворачивает логическое состояние светодиода. Это создаёт эффект мигания с частотой примерно 1 Гц (1 вспышка в секунду).
